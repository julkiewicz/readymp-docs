Launcher `0.25.1` is out alongside [WukongMP SDK 0.2.1](/releases/wukongmp-sdk-021). It shows the option to connect to self-hosted servers for everyone.

<!-- truncate -->

## Changes

* The option to connect to a self-hosted server by its address is now available to every account. See the [installation guide](/wukong-mp/docs/Server/installation) to run your own server.
* The Launcher now displays a message when you try to connect to a server where you are banned ("You're banned from this server") or not whitelisted ("You're not whitelisted on this server"). Bans and the whitelist are managed in the [admin panel](/wukong-mp/docs/Server/admin-panel).

## Updating

The Launcher updates itself. If you are not on `0.25.1` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
