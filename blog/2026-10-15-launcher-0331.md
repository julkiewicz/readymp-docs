Launcher `0.33.1` is out, and the OblivionMP tile is now open to every ReadyM account. There are no more alpha access requests. Together with [OblivionMP SDK 1.0.0-rc.1](/releases/oblivionmp-sdk-100-rc1), this starts the OblivionMP open beta.

This version also changes how mods are downloaded from servers, and adds a Settings window.

<!-- truncate -->

## OblivionMP for everyone

To play, you need a ReadyM account, a PC copy of The Elder Scrolls IV: Oblivion Remastered, and Launcher `0.33.1` or later. The Launcher updates itself, but if OblivionMP is still locked for you, close the Launcher and open it again.

If you are new to OblivionMP, start with [What is OblivionMP?](/oblivion-mp/docs/what-is-oblivion-mp).

## Mod sync

On servers that support it, the Launcher now downloads a server's mods file by file, instead of one archive per mod:

* Only files that you don't have yet are downloaded. Files are shared between servers, and joining a server whose mods haven't changed copies nothing.
* Interrupted or cancelled downloads are resumed, and every file is checked against its hash.
* Files that the server no longer uses are removed.
* Mod sync progress is shown as one progress bar, with the download size and the files being downloaded.
* If a server's mod list is invalid, or two of its mods install the same file, the Launcher shows an error and asks you to contact the server owner.

Servers that don't support it work as before.

## Settings

The new Settings window has the following sections:

* **Language**.
* **Game folders**. The Launcher finds Steam and Epic installations by itself. Set a folder only if it finds the wrong one, or none.
* **Downloads**. Mod files from community servers are kept in a download cache, limited to 2 GB by default. After each join, the files that were used longest ago are deleted until the cache fits the limit. The files of the server you joined are always kept. You can change the limit, see how much disk space the cache uses, or delete all downloaded files.

## Changes in 0.33.0

* Fixed files from an older mod loader version sometimes being left behind after the mod loader was updated.

## Updating

The Launcher updates itself. If you are not on `0.33.1` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
