Launcher `0.33.1` opens **OblivionMP to every ReadyM account**. Until today the OblivionMP tile was locked unless you had alpha access. With the [OblivionMP SDK 1.0.0-rc.1](/releases/oblivionmp-sdk-100-rc1) open beta it is open to everyone, with no access request needed.

This version also changes how the Launcher downloads a server's mods, and adds a Settings window.

<!-- truncate -->

## OblivionMP for everyone

All you need is a ReadyM account, a PC copy of The Elder Scrolls IV: Oblivion Remastered and Launcher `0.33.1` or newer. The Launcher updates itself. If the OblivionMP tile is still locked for you, close the Launcher and open it again to pick up the update.

New to OblivionMP? Start with [What is OblivionMP?](/oblivion-mp/docs/what-is-oblivion-mp).

## Mod sync, file by file

On servers that support it, the Launcher now syncs a server's mods file by file instead of downloading each mod as one archive:

* **Only what you are missing.** Files you already have, from this server or any other, are not downloaded again. Joining a server whose mods haven't changed copies nothing.
* **Resumable and checked.** A download that was cancelled or lost its connection picks up where it stopped. Every file is checked against its hash, and files the server no longer uses are removed from your game.
* **One progress bar** shows the total download size and the files currently in flight.
* **Clearer errors.** If a server's mod list is broken, or two of its mods install the same file, the Launcher names the problem and asks you to contact the server owner.

Servers that don't support it keep working the way they did before.

## Settings

The new **Settings** window collects what used to be scattered around the Launcher:

* **Language.**
* **Game folders.** The Launcher finds Steam and Epic installs by itself. Set a folder only if it picks the wrong one, or none, and switch back to **Find automatically** at any time.
* **Downloads.** Mod files from community servers live in a download cache, limited to 2 GB by default. After each join, the files used longest ago are deleted until the cache fits the limit. The files of the server you just joined are always kept. You can change the limit, see how much space the cache takes, or clear it entirely.

## Since 0.32.0

`0.33.0` fixed files from an older mod loader sometimes being left behind when a server's mod loader was updated.

## Updating

The Launcher updates itself. If you are not on `0.33.1` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
