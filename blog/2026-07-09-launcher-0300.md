Launcher `0.30.0` is out. It ships a new modal for joining servers, which handles password entry, shows the server's description and country, and improves the direct connect flow. It goes together with [WukongMP SDK 0.2.4](/releases/wukongmp-sdk-024), which adds server passwords and the new server list fields.

This is also the Launcher version our OblivionMP pre-alpha testers play with.

<!-- truncate -->

## Joining a server

Joining a server from the list and using **Direct connect** now both open the same join modal:

* If the server is password protected, you enter the password here. Server owners set it with `Server:Password`, see the [installation documentation](/wukong-mp/docs/Server/installation).
* The modal shows the server's description and a flag for its country, from `ServerList:Description` and `ServerList:Country`. See the [server list documentation](/wukong-mp/docs/Server/server-list).

Servers running SDK `0.2.3` can still be joined with this Launcher.

## OblivionMP pre-alpha

The Launcher can now sync mods for OblivionMP servers, the same way it does for WukongMP. It downloads the server's mods and its mod loader, then starts the game. If the Launcher does not find your Oblivion Remastered installation, you can select the folder yourself.

OblivionMP is only available to accounts flagged for alpha testing for now. With this version we can push fixes to our testers and keep our dedicated testing server updated with the latest patches.

## Other changes

* Removed the xModo (魔岛游戏) login and region, following the [retirement of our mainland China hosting](/releases/readym-launcher-0290).
* The server list is now loaded in pages.
* The Launcher can now show a banner with news from us.
* When the Launcher is set to Chinese, documentation links open the [Chinese version of the docs](https://docs.ready.mp/zh-Hans).

## Updating

The Launcher updates itself. If you are not on `0.30.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
