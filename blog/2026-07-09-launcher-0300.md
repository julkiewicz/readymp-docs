Launcher `0.30.0` brings a new way of joining servers. A single join window handles password-protected servers and shows the server's description and country, and direct connect works through it too. It goes with [WukongMP SDK 0.2.4](/releases/wukongmp-sdk-024), which adds server passwords and the new server list fields.

This is also the Launcher our OblivionMP pre-alpha testers play with.

<!-- truncate -->

## Joining a server

Clicking **Join** on a server, or using **Direct connect**, now opens one join window:

* **Passwords.** If the server has a password, you are asked for it here. A wrong password is reported as such, not as a failed connection. Server owners set the password with `Server:Password`, see the [installation guide](/wukong-mp/docs/Server/installation).
* **Description and country.** The window shows the server's description (or "No description") and a flag for its country, taken from `ServerList:Description` and `ServerList:Country`. See the [server list guide](/wukong-mp/docs/Server/server-list).
* **Direct connect** uses the same window, so connecting by address works the same way as joining from the list.

The server list now loads in pages.

Servers still on SDK `0.2.3` keep working with this Launcher.

## OblivionMP pre-alpha

Joining an OblivionMP server now works the same way as joining a WukongMP one. The Launcher downloads the server's mods, and the mod loader from the server itself, then starts the game. If the Launcher can't find your Oblivion Remastered install, you can pick the folder yourself.

The Oblivion tile is only open to accounts flagged for the pre-alpha for now. With this version we can push fixes to testers quickly and keep our dedicated test server on the latest patches.

## Everything else

* **xModo removed.** The xModo (魔岛游戏) login and region are gone from the Launcher, following the [retirement of our mainland China servers](/releases/readym-launcher-0290#mainland-china-hosting).
* **Announcements.** The Launcher can now show a banner with news from us.
* **Chinese docs.** When the Launcher is set to Chinese, its documentation links open the [Chinese version of the docs](https://docs.ready.mp/zh-Hans).

## Updating

The Launcher updates itself. If you are not on `0.30.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
