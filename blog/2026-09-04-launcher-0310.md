Launcher `0.31.0` is out. This version adds an upgraded server list view with new filtering options. You can search by advertised server country, hide empty or full servers, and filter by the **Verified** status. It was released on the same day as [OblivionMP SDK 0.2.0](/releases/oblivionmp-sdk-020) and [WukongMP SDK 0.4.0](/releases/wukongmp-sdk-040).

<!-- truncate -->

## Server list filters

The server list now has the following filters:

* **Country**: all countries, or a single advertised country.
* **Verified**: all servers, verified only, or unverified only.
* **Hide empty** and **Hide full**.
* **Reset** clears all filters.

Server owners set the advertised country with `ServerList:Country`, and get the Verified status with a license key. See the server list documentation for [WukongMP](/wukong-mp/docs/Server/server-list) or [OblivionMP](/oblivion-mp/docs/Server/publishing-your-server).

The Launcher also displays a message when a server has been banned by ReadyM and is not accepting players.

## Changes in 0.30.2 to 0.30.4

* The Launcher installer now installs WebView2 if it is missing.
* When joining an OblivionMP server, the Launcher installs the .NET runtime if it is missing. If the installation requires a PC restart, the Launcher tells you.
* The server list is now the first tab in WukongMP, before co-op and PvP.
* The Launcher adds the Imperial City Arena plugin to Oblivion's plugin list, for the Arena sample game mode in OblivionMP SDK `0.2.0`.
* Fixed not being able to change the game folder when the previously selected folder was deleted.

## Updating

The Launcher updates itself. If you are not on `0.31.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
