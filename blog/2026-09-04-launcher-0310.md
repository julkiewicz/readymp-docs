Launcher `0.31.0` upgrades the server list with new filters. You can narrow it down by the server's advertised country, hide empty or full servers, and filter by **Verified** status. It is out the same day as [OblivionMP SDK 0.2.0](/releases/oblivionmp-sdk-020) and [WukongMP SDK 0.4.0](/releases/wukongmp-sdk-040).

<!-- truncate -->

## Server list filters

The server list now has these filters:

* **Country.** Show only servers that advertise a given country, or all countries.
* **Verified.** All servers, verified only, or unverified only.
* **Hide empty** and **Hide full.**
* **Reset**, to clear all filters at once.

Server owners set the advertised country with `ServerList:Country`, and get the Verified badge with a license key. See the server list guide for [WukongMP](/wukong-mp/docs/Server/server-list) or [OblivionMP](/oblivion-mp/docs/Server/publishing-your-server).

If ReadyM has banned a server, the Launcher tells you it is not accepting players.

## Since 0.30.1

These went out in `0.30.2` to `0.30.4`:

* **Missing runtimes are installed for you.** The Launcher installer sets up WebView2 if your PC doesn't have it. When you join an OblivionMP server and the .NET runtime it needs is missing, the Launcher installs that too, and tells you if the installation needs a PC restart.
* **Servers first.** In WukongMP, the server list is now the first tab, ahead of co-op and PvP.
* **The Arena plugin.** The Launcher adds the plugin for the Imperial City Arena game mode to Oblivion's plugin list, ready for the Arena sample in OblivionMP SDK `0.2.0`.
* **Game folder fix.** You can change the game folder again if the folder you had set before was deleted.

## Updating

The Launcher updates itself. If you are not on `0.31.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
