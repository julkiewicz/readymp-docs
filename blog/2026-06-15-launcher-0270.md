Launcher `0.27.0` has a new interface, rebuilt from scratch. The old one had grown messy, so rather than patch it again we redesigned the whole thing. The splash screen, login and game flow are cleaner, and the layout holds up better across window sizes.

It also fixes `.pak` mods that would not load on some machines.

<!-- truncate -->

## .pak mods load everywhere

Since [0.26.0](/releases/readym-launcher-0260), the Launcher linked a server's `.pak` files into the game folder instead of putting the files themselves there. That worked on most machines and silently failed on others, which is why some of you saw `.pak` mods that just would not load.

The Launcher now copies the files in directly. If a mod was not showing up before, this update should fix it.

## Everything else

* **Translations.** The Launcher's translations were reworked along with the new interface. It is still available in the same nine languages.
* **Tray icon.** Clicking the tray icon brings the Launcher window back.
* **Bigger window.** The default window is larger, and the Launcher's version is shown in the title bar.

## Updating

The Launcher updates itself. If you are not on `0.27.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).

If something still breaks, tell us on the [ReadyM Forum](https://forum.ready.mp) or the [WukongMP Discord](https://discord.gg/wukongmp). Include your Launcher version and a log, and we will dig in.
