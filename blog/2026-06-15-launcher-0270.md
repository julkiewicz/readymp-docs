Launcher `0.27.0` is out. We rebuilt the Launcher front-end from scratch. The old interface had grown messy, so rather than patch it again we redesigned the whole thing. Splash, login and game flow are cleaner, and the layout holds up better across window sizes.

This version also fixes `.pak` mods that would not load on some machines.

<!-- truncate -->

## .pak mod loading

The Launcher used to link `.pak` mod files into the game folder instead of placing the actual files there. That worked on most machines and silently failed on others, which is why some of you saw `.pak` mods that just would not load. It now copies the files in directly. If a mod was not showing up before, this update should fix it.

## Other changes

* Reworked translations, in the same nine languages as before.
* Clicking the tray icon brings the Launcher window back.
* The default Launcher window is larger, and the window title shows the Launcher version.

## Updating

The Launcher updates itself. If you are not on `0.27.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).

If something still breaks, report it on the [ReadyM Forum](https://forum.ready.mp) or the [WukongMP Discord](https://discord.gg/wukongmp), with your Launcher version and a log.
