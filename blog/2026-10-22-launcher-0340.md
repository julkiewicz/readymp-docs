Launcher `0.34.0` gives servers a face. The refreshed server list shows each server's own icon, and a server's Join panel can show the owner's own card. It ships together with [OblivionMP SDK 1.0.0-rc.3](/releases/oblivionmp-sdk-100-rc3), which adds both on the server side.

Playing on Linux through Proton also got a lot simpler.

<!-- truncate -->

## Server icons and cards

* **A refreshed server list.** Servers that set an icon show it next to their name in the list and in their Join panel header.
* **Server cards.** When you open a server's Join panel, the server can show its own card above the Join button: its rules, events, art and links. A label under the card marks it as "Provided by the server owner".
* **Links ask first.** Links on a card open in your web browser, never inside the Launcher. Before opening one, the Launcher shows you the link's domain and asks you to confirm. Links to Discord, YouTube and Twitch open straight away.
* **More in the Join panel.** It now also shows the server's version, and whether it is password protected.

For server owners, icons and cards live in a `branding/` folder next to your server's `config.json`. [Branding](/oblivion-mp/docs/Server/branding) covers what they can contain and the size limits.

## Playing on Linux

The Launcher now runs under Proton, so you can play OblivionMP on Linux through Steam:

1. Add the Launcher installer for Windows to Steam as a non-Steam game. In its properties, set **Compatibility** to "Proton Experimental", then launch it once to install the Launcher and log in.
2. Optional: point the shortcut's **Target** to the installed `ReadyM.Launcher.exe`, so it stops asking to repair the installation each time. This finds it:

   ```bash
   find ~/.local/share/Steam/steamapps/compatdata -path '*ReadyM.Launcher/ReadyM.Launcher.exe'
   ```

3. Connect to a server and let the game compile its shaders. Quit once you reach the main menu.
4. Copy any single-player save into the folder this command prints, to unlock **Continue** in the game's main menu:

   ```bash
   find ~/.local/share/Steam/steamapps/compatdata -mindepth 1 -maxdepth 1 -type d \
     -exec test -e '{}/pfx/drive_c/users/steamuser/AppData/Local/ReadyM.Launcher/ReadyM.Launcher.exe' \; \
     -printf '%p/pfx/drive_c/users/steamuser/Documents/My Games/Oblivion Remastered/Saved/SaveGames\n' -quit
   ```

5. Run the Launcher, connect to a server and click **Continue**.

Steps 3 and 4 will no longer be needed once **New game** also loads multiplayer.

## Everything else

* **Update button on game selection.** The Launcher opens on game selection, which had no update button, so a ready update could go unseen until you picked a game. The button now shows there too.

## Updating

The Launcher updates itself. If you are not on `0.34.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).

Hit a problem? Tell us on the [OblivionMP Discord](https://discord.gg/obmp).
