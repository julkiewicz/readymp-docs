Launcher `0.29.0` has a **server list** built in. Players can find self-hosted WukongMP servers and join them in one click, and server owners can publish their servers to the list for others to discover.

The list ships alongside [WukongMP SDK 0.2.3](/releases/wukongmp-sdk-023), which adds publishing to the server.

<!-- truncate -->

## Server list

**For players:** open the Launcher and you see a list of the self-hosted servers that are online, with their game mode, player count and version. Search by name or game mode, sort by name or by player count, pick a server and click **Join**. You no longer have to ask someone for their IP and type it in, or guess whether a server is still up.

Servers that set a license key from the Player Portal carry a **Verified** badge. If a server is full, the Launcher tells you so and you can try again later.

![The server list in the Launcher](/img/docs/server-list-0.2.3.png)

**For server owners:** update your server to SDK `0.2.3` and set `ServerList:Enabled` in its config, and your server shows up in the list. The [server list guide](/wukong-mp/docs/Server/server-list) walks through it. New to hosting? The **Create server** button in the Launcher opens the [quick start](/wukong-mp/docs/quick-start).

## Mainland China hosting

As part of going all in on dedicated player-hosted servers, we have retired our xModo (魔岛游戏) hosted servers in mainland China. Players there have two options: play on our Hong Kong server, or [set up their own dedicated server](/wukong-mp/docs/Server/installation). The publishing guide above works the same way, and your server shows up in the list for other players to find.

## Since 0.27.0

`0.28.0` and `0.28.1` went out without their own announcement:

* **Game selection.** The Launcher now opens on a game selection screen, which leads to each game's servers. It is the first step towards supporting more than one game.
* **Community links.** WukongMP players can find the QQ group and HeyBox community from the Launcher.
* **Steam fix.** `0.28.1` fixed the Launcher not noticing when a game launched through Steam had closed.

## Updating

The Launcher updates itself. If you are not on `0.29.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
