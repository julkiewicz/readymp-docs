Launcher `0.30.1` is out together with a new OblivionMP alpha build. Make sure to update the Launcher in order to be able to connect to the alpha test server.

<!-- truncate -->

## Launcher changes

* OblivionMP mods can now include `.pak` files. The Launcher copies them into the game, the same way it does for WukongMP since [0.27.0](/releases/readym-launcher-0270).
* Fixed several installation steps for OblivionMP.

## OblivionMP alpha build

Here's the list of changes in the OblivionMP build that comes with this Launcher version:

* Added text chatbox.
* Added UI showing ping and player count in the current area.
* Changed nameplates to show player names rather than NPC names.
* Changed the pickpocket menu to close automatically when the other player moves away.
* Removed idle NPC dialogues.
* Removed the option to enter the dialogue menu with other players.
* Fixed a crash when a pickpocketed player leaves the area.
* Fixed the Clairvoyance spell to work as intended for each individual player.
* Fixed equipped enchanted items showing VFX effects when a player is spawned or enters the area.

Thanks to our testers for the reports and feedback.

## Updating

The Launcher updates itself. If you are not on `0.30.1` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
