Launcher `0.26.0` adds two highly requested features: **mod caching** and **`.pak` file support**. Both work with servers running [WukongMP SDK 0.2.2](/releases/wukongmp-sdk-022) or later.

The new Launcher is backwards compatible with all `0.2.x` releases of the SDK. Older servers can be joined as before, but mod caching and `.pak` file support will not work on them.

<!-- truncate -->

## Mod caching

Mods downloaded from a server are now cached on your machine. If you have already downloaded a mod, you won't download it again the next time you connect to that server, unless the mod has been updated on the server.

This also works across servers. If two servers use the same mod, it is only downloaded once.

The Launcher compares each cached mod with the hash reported by the server. If a cached file does not match, for example because it got corrupted, it is downloaded again.

## .pak file support

Mods can now include `.pak` files, which are loaded by the game at runtime. This also makes `.pak`-only mods possible, without any C# code. See the [SDK 0.2.2 release notes](/releases/wukongmp-sdk-022) for how to set one up.

:::note

In this version, the Launcher links the mods folder into the game's `Paks` folder when the game starts, and removes the link when the game is closed. In [Launcher 0.27.0](/releases/readym-launcher-0270), the link was replaced with copying the files, because the link did not work on some machines.

:::

## Updating

The Launcher updates itself. If you are not on `0.26.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
