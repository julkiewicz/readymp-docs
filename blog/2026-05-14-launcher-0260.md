Launcher `0.26.0` stops re-downloading mods you already have, and lets WukongMP servers ship `.pak` files. Both features need a server running [WukongMP SDK 0.2.2](/releases/wukongmp-sdk-022) or newer.

The new Launcher still connects to every `0.2.x` server. You just won't get caching or `.pak` loading on older ones.

<!-- truncate -->

## Mod caching

When you join a server, the Launcher downloads that server's mods. It now keeps a copy of each one, keyed by the hash the server reports for it. The next time you join, only mods that changed on the server are downloaded again.

The cache is shared between servers, so a mod used by two servers is downloaded once. A cached file that no longer matches its hash, for example because it got corrupted on disk, is thrown away and downloaded again.

## .pak files

Server mods can now include `.pak` files, which the game loads at startup. This makes `.pak`-only mods possible, with no C# code at all. The [SDK 0.2.2 release notes](/releases/wukongmp-sdk-022) explain how to set one up.

:::note

In this version the Launcher links the mods folder into the game's `Paks` folder while the game runs, and removes the link when the game closes. [Launcher 0.27.0](/releases/readym-launcher-0270) replaced the link with a plain copy, because the link silently failed on some machines.

:::

## Updating

The Launcher updates itself. If you are not on `0.26.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
