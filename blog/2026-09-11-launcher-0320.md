Launcher `0.32.0` is out, and it brings Oblivion mod sync. From this version onward, any `.esp` files you put in your mod's `client/` folder are added to the Oblivion plugin list automatically and loaded with the game.

<!-- truncate -->

## .esp files in mods

The server already hands the `client/` folder to everyone who connects (see [Mod management](/oblivion-mp/docs/Server/mod-management)), so this closes the loop. Your plugin ships as part of your mod, players get it when they join, and nobody has to go digging through their `Data` folder or hand-edit a plugin list to play on your server.

* Plugins are added to the plugin list in the order in which the mods are loaded.
* The Launcher makes a backup of the game's `Plugins.txt` before changing it. When the game is closed, the Launcher removes the plugin files it copied and restores the original `Plugins.txt`.
* This requires Launcher `0.32.0` or later, so check that you are on the current version before you test. If not, restarting the Launcher should start the update.

## Updating

The Launcher updates itself. If you are not on `0.32.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
