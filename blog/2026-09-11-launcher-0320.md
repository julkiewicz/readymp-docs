Launcher `0.32.0` brings Oblivion mod sync: `.esp` plugin files in an OblivionMP mod are now installed and loaded with the game automatically.

<!-- truncate -->

## .esp plugins in mods

From this version on, any `.esp` files you put in your mod's `client/` folder are added to Oblivion's plugin list and loaded with the game.

The server already hands the `client/` folder to everyone who connects (see [Mod management](/oblivion-mp/docs/Server/mod-management)), so this closes the loop. Your plugin ships as part of your mod, and players get it when they join. Nobody has to dig through their `Data` folder or edit a plugin list by hand to play on your server.

A few details:

* **Load order.** Plugins from mods are added in the order the mods load.
* **Cleanup.** The Launcher backs up the game's `Plugins.txt` before adding to it. When the game closes, it removes the plugin files it copied and restores your original plugin list.
* **Requires `0.32.0`.** Players on older Launchers don't get the plugins. If you are not on the current build, restarting the Launcher should trigger the update.

## Updating

The Launcher updates itself. If you are not on `0.32.0` yet, restart it, or download it from the [Player Portal](https://portal.ready.mp).
